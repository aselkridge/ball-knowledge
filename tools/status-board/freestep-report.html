One step a turn
is now free

The rule DESIGN.md has promised since July, shipped exactly as written: each offensive turn, a player without the ball can step ONE square for nothing, and the main action is still live. The defence does not answer the step; it answers the action.

"Design free off ball movement please and make sure it's clear in the in game coaching and drills and rulebook."Aaron, 2026-08-11 · and 08-10: "I am pretty sure that we moved to all movement before the main action is free... I am not sure why that never shipped to the game"

Before and after · the same staged move

Same player, same square. The only difference is whether this turn's free step is still available, and the game says which one you are about to spend BEFORE you commit. That label is the visible-incentive rule from 08-02 doing its job.

The rule, in five measured claims

All seven checks in turn-economy-check.mjs pass, a sabotage included. That file used to be the deliberate failure proving the doc and the game disagreed; it is now the guard that keeps them agreeing.

  • An off-ball 1-square step is FREE: the offence keeps the turn
  • The SECOND step the same turn spends the action
  • The ball carrier never steps free
  • An off-ball move of 2+ squares is a main action, not a step
  • D33: the step drew no defensive slide; the main action drew exactly one

Where it is taught, all three places you asked for

Rulebook · Your Possession now leads with the free step and carries its own RUN THE DRILL button.

Drills · a new drill, The Free Step: tap the man in the corner, step him one square, watch it cost nothing, then make the real move. 11 drills now.

In-game coaching · a once-per-phone coach tip fires the first time a player uses the step, and the stage button itself reads Free step ✓ whenever one is available.

Deliberately left alone

The open-man bonus (D34) did not ship with this. Ending the turn uncovered and getting something for it needs your taste on WHAT the something is, and your 08-02 ruling binds it to a visible incentive. Options are filed in V0 D34 for the next batch. The step already pays for itself through spacing, screens and cuts, which is what the drill teaches.

The defence's toolkit is untouched: same slides, same steals, same one answer per main action, so the economy that measured fair on 08-10 still holds.
