table · where col=value, col=value · join table, table · count by col · sort col desc, col — sort takes as many columns as you like, in order.
col!=value excludes · col=* means any non-empty · col= means empty. Anything you build on the other tab writes itself here, so the syntax teaches itself. Ctrl/Cmd+Enter runs.
SQL works too, for the shape you would actually type: SELECT * FROM person_stats JOIN people WHERE league_id='wnba' ORDER BY ppg DESC or SELECT confidence, COUNT(*) FROM facts GROUP BY confidence — it is translated into the line above, which is why you see that change too.
The tables ARE a database — 23 of them, with keys and joins. What is not here is a SQL engine: they are files this page reads, and about fifty lines translate your SQL into the plain form. So these are the translator’s limits, not the data’s — no OR, no HAVING, no subqueries, and COUNT(*) is the only sum it does. The SELECT list is ignored; use Columns for that.
